LiftLibrary

A web app that draws a barbell loaded with the plates you pick, so you can see exactly what a lift looks like before you walk up to the rack. It handles Olympic, women's, and training bars, lb and kg plates, and collars, and lets you log personal records to your own library behind a login.

Recently migrated the front end to React with Vite and moved the back end to a Flask JSON API with hashed-password accounts. Next up: deploying to a server.
